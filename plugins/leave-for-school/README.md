# Leave for School — a Home Screens plugin

Weekday-morning countdown to the bus or school departure, turning amber then red as time runs out.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-plugins/releases/latest/download/leave-for-school.tgz
```

Build: `npm install && npm run build`
