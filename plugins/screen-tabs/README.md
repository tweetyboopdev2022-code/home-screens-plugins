# Screen Tabs — a Home Screens plugin

A row of big buttons to jump between screens — Home, each person, Planning, Shopping, News.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-plugins/releases/latest/download/screen-tabs.tgz
```

Build: `npm install && npm run build`
