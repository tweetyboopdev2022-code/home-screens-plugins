# Pet Care — a Home Screens plugin

Tap-to-log daily pet jobs (fed, walked, litter) with the time they were done; resets every morning. Optional monthly reminders.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-plugins/releases/latest/download/pet-care.tgz
```

Build: `npm install && npm run build`
