# Heads-up — a Home Screens plugin

Only what needs attention right now: bins going out, overdue chores per person, Souper Cubes running low, tomorrow's dinner not planned. Says All clear otherwise.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-plugins/releases/latest/download/heads-up.tgz
```

Build: `npm install && npm run build`
