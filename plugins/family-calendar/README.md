# Family Calendar — a Home Screens plugin

Day columns or a month grid where event titles wrap. Weather on each date; tap a date to see the whole day with the weather where each event happens. 'Day N' school badges, icons, per-person colours and filter buttons.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-plugins/releases/latest/download/family-calendar.tgz
```

Build: `npm install && npm run build`
