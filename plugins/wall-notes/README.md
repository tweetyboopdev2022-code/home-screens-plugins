# Wall Notes — a Home Screens plugin

Sticky notes from a Todoist project — post a note from your phone, tap it on the wall to take it down.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-plugins/releases/latest/download/wall-notes.tgz
```

Build: `npm install && npm run build`
