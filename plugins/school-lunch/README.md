# School Lunch — a Home Screens plugin

Today's school lunch from calendar events (e.g. 'School Lunch: Taco Bowl'); shows tomorrow's in the afternoon.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-plugins/releases/latest/download/school-lunch.tgz
```

Build: `npm install && npm run build`
