# Hero Header — a Home Screens plugin

Big time, date and greeting with today's weather and the next event — one card for the top of a screen.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-plugins/releases/latest/download/hero-header.tgz
```

Build: `npm install && npm run build`
